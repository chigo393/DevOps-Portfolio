# Chijioke Patrick | DevOps Portfolio

A responsive, single-page DevOps engineering portfolio with eight STAR case studies and a downloadable PDF.

## Publish free with GitHub Pages

1. Sign in to GitHub, then create a **public** repository named `devops-portfolio`.
2. Upload `index.html` and `portfolio.pdf` from this folder to the repository root. Commit changes.
3. Open the repository's **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**. Save.
5. After publication, visit `https://YOUR-GITHUB-USERNAME.github.io/devops-portfolio/`.

Upload the **contents of the folder**, not the ZIP as one file.

## Site files

- `index.html`: self-contained HTML, CSS and minimal JavaScript; no build tooling required.
- `portfolio.pdf`: complete PDF portfolio linked from the website.

## Customize

- Edit the content in `index.html` to update any projects or claims.
- Replace `portfolio.pdf` to update the downloadable portfolio.
- Add your GitHub profile and actual repositories when available.

No Jenkins experience has been claimed. Project descriptions are drawn from documented hands-on tasks and do not assert unsupported performance metrics.
