04 / INCIDENT RESPONSELinux

Resolved Apache, MariaDB and Tomcat issues

Apache · Sendmail · MariaDB · Tomcat

Apache could not use port 5000 due to Sendmail. MariaDB failed to create its PID file due to directory permissions.

Result: Apache service restored on its required port, MariaDB startup fixed and Tomcat endpoint verified.
View project details
Situation

Service failures prevented applications from running on configured ports.

Task

Find the root causes, restore services, and verify accessibility.

Action
  • Checked port listeners to identify Sendmail bound to 127.0.0.1:5000.
  • Changed the conflicting configuration, restored Apache on port 5000 and reviewed firewall rules.
  • Used curl from the jump host to test the endpoint.
  • Corrected /run/mariadb ownership to mysql:mysql and suitable permissions.
  • Deployed ROOT.war to Tomcat on port 6300 and tested HTTP access.
Result

Fixed Apache and MariaDB availability issues and validated the Tomcat deployment.
